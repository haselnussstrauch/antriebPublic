# antriebPublic

Öffentliche Ablage für Bilder, die **antrieb** (https://antrieb.app) auf Instagram veröffentlicht.

Metas Content-Publishing-API lädt kein Bild hoch, sondern holt es von einer öffentlichen URL. Dieses
Repo ist genau dafür da – und für sonst nichts: keine Texte, keine Entwürfe, keine Zugangsdaten. Es
landet hier nur, was freigegeben ist und ohnehin öffentlich auf Instagram steht.

Struktur: `instagram/JJJJ-MM-TT-thema/bild-N.jpg`. Die Bilder entstehen aus HTML/CSS-Vorlagen im
privaten Hauptrepo; Adressen für die API: `https://raw.githubusercontent.com/haselnussstrauch/antriebPublic/main/instagram/<ordner>/bild-N.jpg`
